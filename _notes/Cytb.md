### Analysis of the Cytb marker amplified with the primers:

> **L14996**
> AAYATYTCWGYHTGATGAAAYTTYGG

> **H16064**
> CTTCANTYTTTGGYTTACAAGRCC

---

1- Select the corresponding genetic code (usually 2 or 5).

2- In parameters, set **Barcode length (bp)**:

```
1062 bp (includes stop codon)
```
 *The program automatically removes the stop codon region and returns a barcode of*

```
1032 bp (stop codon trimmed)
```

3- **Minimum length (bp)**: 800

4- **Maximum read length deviation from barcode length (bp):** 150

---
### These primers work relatively well in birds and mammals, and less efficiently in other groups
